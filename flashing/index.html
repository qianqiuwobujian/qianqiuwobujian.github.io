新手烧录入门

先认对开发板，
再把固件装进去。

不同 ESP32 芯片与板型不能混用固件。本站会逐步给实测通过的项目增加一键烧录；需要修改代码、字体或网络信息时，仍使用 Arduino IDE。

规划中的新手方式

固件羊一键烧录

连接开发板，打开项目专属入口，按页面提示选择串口并烧录。只有板型和固件实测匹配的项目才会开放按钮。

  • 适合不需要修改源代码的成品固件
  • 需要 Chrome 或 Edge、数据线和正确驱动
  • 字体或图片写入文件系统时，需使用完整镜像
打开固件羊当前项目码尚未逐一验证，请先使用 Arduino IDE。
当前通用方式

Arduino IDE

适合修改 Wi-Fi、计时时长和源代码，也便于安装项目依赖、查看详细编译报错。

  • 从 Arduino 官网安装 IDE
  • 添加 Espressif ESP32 开发板支持
  • 安装项目页列出的库，选择正确板型和端口
下载 Arduino IDE

通用步骤

Arduino IDE 烧录

  1. 安装软件安装 Arduino IDE。需要中文时，在 File → Preferences → Language 中选择中文。
  2. 添加开发板支持在“附加开发板管理器网址”加入 https://espressif.github.io/arduino-esp32/package_esp32_index.json，然后安装 esp32 by Espressif Systems。
  3. 准备项目文件把 .ino、项目自带的 .h 字体或库文件放在教程指定目录，路径不要包含中文。
  4. 安装依赖在库管理器中安装项目页列出的库。缺少字体或头文件时，先确认它们是否需要与主程序同目录。
  5. 选择板型与端口根据项目页选择 ESP32C3、ESP32C6 或 ESP32S3 等完整板型，并选择插入设备后出现的新端口。
  6. 验证并上传先点击验证。编译通过后再上传；若卡在连接阶段，可尝试按住 BOOT 后重新上传。
检查表

报错时先看这几项

01

数据线

确认不是只能充电的线。

02

板型

C3、C6、S3 与普通 ESP32 不可混选。

03

端口

拔插开发板，观察新出现的 COM 口。

04

项目路径

使用纯英文、层级较短的路径。

05

依赖库

按报错中的缺失头文件检查库与字体。

06

下载模式

必要时使用 BOOT / RST 组合键。
