制作要点

按这个顺序开始

  1. 01安装 ESP32 开发板支持与 USB 驱动。
  2. 02下载固件并确认两个文件位于正确目录。
  3. 03安装 Adafruit SSD1306，保留随包提供的 RoboEyes 头文件。
  4. 04选择 ESP32C3 Dev Module 与正确端口。
  5. 05验证后上传；必要时用 BOOT/RST 组合进入下载模式。

经验与注意事项

  • 手机连接“桌面机器人”Wi-Fi 后，苹果手机通常会自动打开控制页；其他设备可访问 192.168.4.1。
  • L298N 必须购买迷你版，注意不要买成大号模块。
  • 框架图中 26 mm 是放置屏幕的关键尺寸，其余尺寸可按外观调整。
