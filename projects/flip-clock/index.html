制作要点

按这个顺序开始

  1. 01下载并解压固件，路径不要包含中文。
  2. 02在 Arduino IDE 安装 ESP32 开发板支持。
  3. 03确保 .ino 与 4 个字体 .h 文件位于同一目录。
  4. 04修改 Wi-Fi 名称、密码和番茄计时时长。
  5. 05选择 ESP32C6 Dev Module 与正确端口，先验证再上传。

经验与注意事项

  • 默认向右翻转 90°进入 30 分钟专注，向左翻转 90°进入 5 分钟休息。
  • 如果上传卡在连接阶段，可按住 BOOT 后重试。
  • 屏幕不亮时优先检查 CS、DC、RST 与背光引脚。
