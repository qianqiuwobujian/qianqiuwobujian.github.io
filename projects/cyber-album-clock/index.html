04

制作与使用步骤

  • 安装 Arduino IDE 并切换中文。
  • 安装 ESP32-S3 开发板支持包与 TFT_eSPI。
  • 打开 frameclock V1.0 最终版。
  • 修改 Wi-Fi 名称与密码。
  • 选择 ESP32S3 Dev Module 后上传。

注意事项

  • 新版可建立 SmartWatch_AP 热点，密码 12345678；连接后访问 192.168.4.1 配网。
  • 如果 ESP32-S3 无法稳定访问配网页面，可按原文检查 APSTA 模式并关闭 Wi-Fi 睡眠。
  • 旧文档的更新日期缺少年份，后续补版本号比只写日期更清楚。
