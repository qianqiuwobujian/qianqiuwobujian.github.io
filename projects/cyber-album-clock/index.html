制作要点

按这个顺序开始

  1. 01安装 Arduino IDE 并切换中文。
  2. 02安装 ESP32-S3 开发板支持包与 TFT_eSPI。
  3. 03打开 frameclock V1.0 最终版。
  4. 04修改 Wi-Fi 名称与密码。
  5. 05选择 ESP32S3 Dev Module 后上传。

经验与注意事项

  • 设备会建立 SmartWatch_AP 热点，密码 12345678；连接后访问 192.168.4.1 配网。
  • 若配网页面连接不稳定，可检查 APSTA 模式并关闭 Wi-Fi 睡眠。
